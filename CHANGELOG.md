# Changelog

## 3.79.0 — 2026-10-05

Одна канонічна адреса сайту: www і без www, http і https більше не дублюють сторінки.

- 301-редирект на адресу з APP_PUBLIC_URL: «чужий» варіант www/без www та http на https-сайті; POST, вебхуки, cron і локальні хости не чіпаються; вимикається змінною COMMERCE_CANONICAL_REDIRECT=0.
- robots.txt закриває службові й параметричні адреси (сортування, ціна, ліміт, utm, gclid, кошик, порівняння, обране).
- .htaccess: заборонено лістинг каталогів і видачу дот-файлів, бекапів, дампів і логів.
