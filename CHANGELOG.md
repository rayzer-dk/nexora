# Changelog

Nexora Commerce has a single product line on the `main` branch. Only release-level changes are listed.

## 3.63.0 — 2026-10-05

Product options with price actions, weight and display, weight in delivery, own search words, optional review e-mail.

- Option values: a price action "+", "−" or "=" (sets the price of the combination), a weight difference in grams and a start stock for the variants that are generated; every option can be shown as buttons, a dropdown or radio buttons.
- Product page: hovering a value shows what choosing it does to the price ("+50 ₴", "−20 ₴"); the picture of the value still replaces the main photo.
- Delivery methods: an extra price per kilogram above an included weight and a maximum order weight, from the weight set in the product; checked at checkout and in the totals.
- Search: a field for own words ("айфон - iPhone", one line per word, several words per line) in Catalog → Search.
- Reviews: the guest e-mail is optional; a separate switch makes it required.
- Captcha: letters are turned further for confusion.
