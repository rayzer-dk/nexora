# Changelog

## 3.82.0 — 2026-10-05

Шаблони ALT-тексту для фото товарів.

- Шаблон ALT із змінними {name} {brand} {category} {sku} {n} {store} окремо для головного й додаткових фото: фото без власного ALT одразу показують текст за шаблоном на вітрині мовою відвідувача.
- Каталог → «ALT фото товарів»: попередній перегляд, що зміниться, і кнопка «Записати в базу» для порожніх (або всіх) полів.
