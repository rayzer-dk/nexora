# Changelog

Nexora Commerce has a single product line on the `main` branch. Only release-level changes are listed.

## 3.51.0 — 2026-10-05

Fuller admin sections and language tabs.

- Language tabs (OpenCart style): every translatable field in the admin (storefront texts, menu, badges, units) has a tab per active store language with filled/empty marks; the chosen language is remembered.
- Delivery and payment methods: own title and text per language, fee, free-over threshold, minimum and maximum order amount; the checkout shows the fee, recalculates the total and refuses orders outside the limits.
- Customer card: orders, totals, notes, status; the customers list has filters, sorting and totals.
- Promotions: edit, duplicate, delete, usage statistics and redemption history.
- Inquiries: filters by text, status and type, status tiles with counts.
