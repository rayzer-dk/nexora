# Changelog

Nexora Commerce has a single product line on the `main` branch. Only release-level changes are listed.

## 3.50.0 — 2026-10-05

Icons everywhere, recovery analytics, statuses, editor.

- Icon picker (all Lucide icons, search, blurred page) is used for menu items, product badges and categories (shown on the category tile) and for the newsletter and benefit cards; the text editor has an "Insert an icon" button, the icon is drawn on the page from its name.
- Abandoned carts: number of e-mails sent per cart and a new Analytics tab: contacts saved, e-mails sent, who ordered after which e-mail (first or repeat), revenue after reminders, orders placed at once without an e-mail.
- Coloured status chips in every admin table where a status is shown (orders, shipments, returns, rewards, B2B, builder revisions).
- HTML source editor: 20 more colour themes (32 in total).
- Colour tools in the editor and in the admin forms are normal-size controls with a thin colour bar.
