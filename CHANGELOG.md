# Changelog

Nexora Commerce has a single product line on the `main` branch. Only release-level changes are listed.

## 3.69.1 — 2026-10-05

Fix for the release checks.

- The list of shoppers waiting for a product uses icons instead of text arrows (the icon audit of the release checks failed on 3.67.0).

## 3.69.0 — 2026-10-05

Downloads centre: editing and search.

- A downloaded file can be edited (name, group, order, description) without uploading it again, and the list has a search by name, group and description.
