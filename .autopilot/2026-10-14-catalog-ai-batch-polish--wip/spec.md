# Спецификация: каталог, ИИ-подстановка, пакетный перевод, редактор, логотип, подсказки, релиз 4.0.0

Профиль Quality PRO: **STANDARD** с элементами DEEP для T06/T07 (новые таблицы, cron, ИИ) и T11 (релиз). Тип изменений: feature + bugfix + UI. Базовый коммит `2aaa34d2`. Откат: `git revert` коммитов тасков; новые таблицы — обратимые миграции (`down()` удаляет только новые таблицы).

## Задача

Владелец ставит Nexora впервые и сравнивает с конкурентами. В списках каталога ему не хватает информации (сколько товаров в категории, остатков) и быстрых действий (обнулить, поправить остаток прямо в списке). Статусы занимают место. ИИ-кнопки пишут «готово», но текста не видно. Редактор цвета неудобен. Логотип мелкий, а название «Nexora» показывается, хотя его убрали. Подсказок мало. Переводить каталог по одному полю долго — нужен пакетный перевод по языкам. Нужен готовый архив и понятный ответ разработчикам: как писать модули.

## Решение

Списки товаров и категорий становятся информативнее и быстрее; ИИ всегда показывает, что сгенерировал и куда вставил; весь каталог переводится на выбранные языки в фоне с прогрессом по каждому языку и словарём «не переводить»; ИИ массово готовит описания и SEO для выбранных товаров с проверкой перед применением; редактор цвета — спектр, HEX, ряд популярных и ряд последних; логотип настраивается по размеру, имя скрывается везде; на ключевых экранах — подсказки; разработчики получают полное руководство с рабочими примерами; выходит релиз 4.0.0.

## Решения по реализации

- **Остатки** — один сервис `ProductStockService` вместо прогона через `ProductWriter::update` (быстрая цена так делает и перезаписывает всё): прямые `UPDATE mc_stock_level` по складу рынка с наивысшим приоритетом — та же точка, что пишет `ProductWriter`, поэтому формы и списки согласованы. `row_version+1`, событие `PRODUCT_UPDATED` (source `stock`) для поиска/фидов.
- **Пакетная очередь** — по образцу `mc_import_image_queue` (БД + cron + кнопка, без Messenger: в проекте нет транспортов). Две таблицы: пакеты и задания. Ограничение: обработка сериями с бюджетом времени, блокировка через `GET_LOCK`.
- **Один запрос на сущность×язык** — новая задача `translate_fields`: JSON `{field: text}` на входе и выходе; длинные HTML-поля (> 6000) — отдельными частями через существующий `TranslationChunker`.
- **Словарь** — в `mc_ai_glossary`; «не перекладати» — маркеры `⟦T1⟧` (заменяются до вызова, восстанавливаются после, проверка, что все маркеры вернулись; иначе — ошибка «модель зіпсувала терміни», повтор).
- **Цветовой выбор** — свой лёгкий компонент на Vue (без новых зависимостей): canvas-градиенты не нужны, CSS-градиенты + указатель.
- **Логотип** — настройка `brand.logo_height` в presentation settings, CSS-переменная `--mc-logo-height`.
- **Релиз на Windows** — bash-скрипт требует rsync/zip; упаковка повторяется PHP-скриптом `tools/package-production.php` с теми же исключениями, проверками и манифестом (кросс-платформенно), `.sh` остаётся.
- **Публикация** — `gh release create v4.0.0` (разрешено владельцем на брифинге).
