# 02 — ИИ: видно, что сгенерировано и куда вставлено

**Требования:** R06, R07
**Зависит от:** 01
**Зона:** `assets/admin/admin-runtime.js` (AI helpers, lines 1–150) · `themes/default/templates/admin/_ai_box.html.twig` · `themes/default/templates/admin/catalog/_ai_photo.html.twig` · AI-helper markup in `themes/default/templates/admin/catalog/product_form.html.twig` · `themes/default/templates/admin/customer_experience/index.html.twig` (AI parts) · `assets/admin/admin-runtime.css` (AI helper rules) · `tests/e2e/ai-result-visible.spec.ts`
**Волна:** 2
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

После нажатия любой ИИ-кнопки (черновик описания, текст категории, SEO-мета товара/страницы/статьи, карточка по фото, ответ на отзыв) в блоке ИИ появляется сам сгенерированный текст по каждому полю, подпись «Вставлено в: <поле>» и кнопка «Показати поле», которая открывает нужную вкладку формы, прокручивает к полю и подсвечивает его. «Вставлено» пишется только если поле реально заполнено; иначе — понятная ошибка и текст с кнопкой «Копіювати».

## Из брифа, дословно

> «при генерации текста ИИ нет показа  самого текста. кнопку нажимаю, пишет сделано а где ничего нет. не подставляет.»

## Разделы спецификации

Истории 12–15; `interfaces.md` → «AI insertion feedback (T03)»; `notes.md` §3 (таблица мест, вкладки, где статус ставится безусловно).

## Критерии приёмки

- [ ] Во всех местах из таблицы `notes.md` §3 после ответа ИИ в блоке есть превью каждого поля (до 300 символов, «Показати повністю») и «Вставлено в: <метка поля>»
- [ ] «Показати поле» открывает вкладку товара (`data-product-tab`) или общую вкладку (`data-tabs`), прокручивает и подсвечивает поле ~2 с; для поля с визуальным редактором подсвечивается редактор
- [ ] Ни одно поле не найдено → статус-ошибка «Не вдалося вставити: поле не знайдено», превью с «Копіювати»; пустое значение поля от ИИ → сообщение, какое поле пришло пустым
- [ ] Фото-карточка и черновик пишут только в поля своей формы (`closest('form')`), не в первое `[name=name]` документа
- [ ] Новые тексты — ключи `admin.ai.*` (uk-UA + en-US); `npm run typecheck`/eslint 0 ошибок; e2e-спек с подменённым ответом ИИ (как `tests/e2e/ai-translate-all.spec.ts`) проходит на изолированной копии
