**Требования:** R09, R10, D03
**Зависит от:** 08
**Зона:** `themes/default/templates/admin/system/extension_settings.html.twig` · `src/Core/Extension/**` · API webhook subscriber and order/payment event publishers (`src/Modules/Api/**`, the event payload builders in `src/Modules/Order/**` and `src/Modules/Payment/**` that publish the three events) · product block schema handling in `src/Modules/ProductPage/**` / `src/Modules/Appearance/Builder/**` (builder settings for extension blocks only) · `docs/DEVELOPER_MODULES_UK.md` (sections that describe these limits) · `tests/Unit/Extension*Test.php`, `tests/Unit/ApiWebhook*Test.php`

**Модель:** сильная

## Что должно заработать

Модуль с многоязычными полями настроек сохраняет текст на каждом языке; при обновлении модуля его настройки остаются, и trusted-модуль может их прочитать; внешние системы получают вебхуки об отмене и завершении заказа и о смене статуса оплаты; `list-events` показывает то, что реально публикуется; настройки блока товара из модуля появляются в конструкторе страницы товара. Документ разработчика больше не описывает эти места как ограничения.

> «легко вообще писать и удобно? система гибкая и адаптируется. все можно настроить с помощью модулей.»

## Критерии приёмки

- [ ] Сначала воспроизвести каждый из пяти дефектов тестом (красный), потом чинить
- [ ] `multilingual_text`/`multilingual_textarea`: поле на каждый включённый язык, сохранение и показ после перезагрузки (на изолированной копии с примером `hello-settings` или своим)
- [ ] Обновление версии модуля переносит сохранённые настройки; поля, которых нет в новой схеме, не теряют совместимость (новые — по умолчанию); trusted-модуль читает свои настройки через `TrustedExtensionContext` (метод назван в отчёте), раздел в документе обновлён
- [ ] Три события несут `store_id` и доставляются подписке API-вебхука (юнит/интеграционный тест на подписчике); существующие подписчики не ломаются
- [ ] `commerce:extension:list-events` выводит реально публикуемые события (или явно помечает зарезервированные), совпадает с документом
- [ ] Поля схемы блока товара модуля видны и сохраняются в конструкторе страницы товара (или, если это требует переработки конструктора, — `BLOCKED` с объяснением, без частичной поделки)
- [ ] PHPUnit (3 известных Windows-падения), `bin/admin-access-check.php`, `bin/i18n-template-check.php`, `bin/full-release-static-check.php` — OK
