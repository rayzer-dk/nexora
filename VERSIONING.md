# Application release versioning

All new releases of our applications must use exactly three single decimal digits separated by dots (X.Y.Z, `^[0-9]\.[0-9]\.[0-9]$`). Increment Z by one; at 9 carry to Y, and at Y=9 carry to X. Examples: 1.7.9 → 1.8.0; 1.9.9 → 2.0.0. At 9.9.9 obtain explicit user guidance. Compare versions numerically by component. Migrate legacy multi-digit application releases to a strictly greater compliant version; do not rewrite history or published tags. Apply consistently to application manifests, UI, package metadata, archive names, update endpoints and CI. This applies to all application release branches, not third-party dependency versions, protocol versions or upstream OpenCart/ocStore compatibility identifiers. Existing CodeCart four-component platform/compatibility identifiers remain unchanged until explicitly migrated.
