# Accessibility Baseline

The EU storefront targets EN 301 549 / WCAG 2.2 AA as the engineering baseline for e-commerce accessibility.

Core requirements include semantic landmarks, keyboard navigation, visible focus, labelled form fields, programmatically associated errors, screen-reader status updates, sufficient contrast, no color-only meaning, reduced-motion support, usable zoom/reflow, touch-friendly controls and enough time to complete checkout actions.

The platform stores an Accessibility Profile per store, including target standard, conformance status, audit dates and a versioned Accessibility Statement document. Theme extensions may change presentation but cannot remove core accessibility semantics from protected commerce components.
