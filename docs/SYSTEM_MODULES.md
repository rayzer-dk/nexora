# Protected system modules

The complete commerce distribution ships with critical capabilities as protected system packages.

Protected packages cannot be uninstalled through normal module management because removing them would make the platform structurally incomplete. They are versioned and updated independently behind stable contracts.

Protected baseline includes the complete ready-to-sell feature set: Catalog/Pricing/Inventory, Customer/Cart/Checkout/Orders/Returns, Shipping/Payment/Tax, Promotions/Coupons/Gift Cards/Loyalty, Reviews/Q&A/Wishlist/Compare, Markets/B2B capabilities, Media/Search/SEO/Redirects, CMS/Blog/Navigation/Page Builder, Google Commerce/Feeds/Marketing/Analytics, Identity/Notifications, API/Webhooks, Queue/Scheduler, Import/Export, Backup/Restore, Update Engine, Health, Security/Audit, Appearance, Logs and Developer Tools. Some specialized features are installed but disabled by default, so they add no storefront load until enabled.

Third-party and business-specific extensions remain removable. Removing them must not edit Core files or damage historical orders. Their data is retained by default until an explicit purge is requested.
