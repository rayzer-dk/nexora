# System URLs

System-page URLs use stable English paths for every locale. The visible page title is translated; the route itself is not transliterated or renamed when the language changes.

Core routes:
- catalog: `/catalog`
- brands: `/brands`
- new products: `/new`
- sale: `/sale`
- search: `/search`
- cart: `/cart`
- checkout: `/checkout`
- account: `/account`
- login: `/login`
- register: `/register`
- orders: `/orders`
- wishlist: `/wishlist`
- compare: `/compare`
- order tracking: `/track-order`
- return request: `/return-request`
- shipping: `/shipping`
- payment: `/payment`
- returns: `/returns`
- warranty: `/warranty`
- contact: `/contact`
- about: `/about-us`
- blog: `/blog`
- FAQ: `/faq`
- privacy: `/privacy-policy`
- cookies: `/cookie-policy`
- terms: `/terms-and-conditions`
- accessibility: `/accessibility`

Service pages such as cart, checkout, account, search and order tracking are noindex. Public information pages can be indexable. Entity namespaces are also English and stable, e.g. `/brand/...` and `/blog/...`.
