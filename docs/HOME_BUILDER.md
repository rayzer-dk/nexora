# Конструктор головної: банери, історія при прокрутці, відео

Де: Адмінка → Вигляд → Конструктор головної. Кнопка «Додати блок» містить: Банер, Історія при прокрутці, Відео-банер, а також Hero, Категорії, Товари, Статті.

## Для кожного блоку (усі типи)
- **Пристрої.** Галочки «Комп’ютер / Планшет / Телефон» справді ховають блок на відповідному екрані: телефон < 768 px, планшет 768–1023 px, комп’ютер ≥ 1024 px. Прихований блок не відображається взагалі.
- **Стиль.** Фон (колір `#rrggbb`, `rgb(...)` або простий градієнт `linear-gradient(90deg,#0b63f6,#7c3aed)`), колір тексту, відступи (`padding`, `margin`), вирівнювання. Інші значення система ігнорує.
- Блоки можна вмикати/вимикати, дублювати, видаляти й перетягувати.

## Банер
Кілька банерів поспіль складаються в один ряд: 2 по 1/2, 3 по 1/3 або 2/3 + 1/3. На телефоні банери йдуть один під одним.
- Зображення для комп’ютера (рекомендовано 1600×640) і окреме для телефона (800×800, необов’язково).
- Заголовок, текст, кнопка, посилання (весь банер клікабельний).
- Ширина: на всю / 2/3 / 1/2 / 1/3. Висота: низький, середній, високий, дуже високий.
- Положення тексту: сітка 3 × 3 (угорі/посередині/внизу × ліворуч/по центру/праворуч).
- Колір тексту — поле «Колір тексту» у стилі блоку; затемнення зображення 0–80 %.
- Без зображення банер — кольорова плитка з кольором зі стилю «Фон».

## Історія при прокрутці
До 4 кроків (заголовок, текст, картинка). На комп’ютері картинка «прилипає» до екрана й плавно змінюється, коли читач доходить до наступного кроку; можна вибрати, ліворуч чи праворуч картинка. На телефоні кожен крок показує свою картинку над текстом. Без JavaScript видно перший крок.

## Відео-банер
Відео-фон із заголовком і кнопкою.
- Посилання на `.mp4` або `.webm` (https або `/media/...`) і постер.
- Відео вмикається лише на комп’ютері, без звуку, зациклене, коли банер з’являється в полі зору; є кнопка паузи. Якщо у відвідувача ввімкнено «зменшити рух» або економію трафіку, а також на телефоні (якщо не дозволено окремою галочкою), показується тільки постер.
- Порада: відео до 5–8 МБ, 10–20 секунд, без звуку; постер — той самий кадр.

## Категорії на головній
Блок «Категорії»: розташування (сітка або горизонтальна стрічка), колонки, ліміт, фото й кількість товарів, порядок (вручну, за назвою, за кількістю товарів, нові спочатку).
Порядок «вручну» береться з поля «Порядок» у категорії; у списку категорій його можна змінити прямо в таблиці.
