# Built-in system modules

The distribution is intended to include the full baseline needed to sell without mandatory third-party plugins.

Core commerce: Catalog, Categories, Brands, Attributes, Options/Variants, Pricing, Inventory, Warehouse, Customer, Cart, Checkout, Order, Returns, Payment, Shipping, Tax, Promotion, Coupons, Gift Cards, Loyalty, Reviews, Q&A, Wishlist, Compare, Saved Carts, B2B price lists and Multi-store/Markets.

Content and discovery: CMS, Blog, Navigation, Page Builder, Search, Recommendations, Media, Files and Redirect manager.

Growth: SEO, Structured Data, Feeds, Google Merchant integration, Marketing Event Layer, Ads connectors, Analytics, Attribution, Abandoned Cart, Email/SMS/Push notifications and Campaigns.

Operations: Import/Export, Queue, Scheduler, Backup/Restore, Update Engine, Logs, Audit Log, Health Center, Permissions, API/Webhooks and Developer Tools.

Optional capability packs: AI, advanced warehouse, ERP/CRM connectors, marketplaces, country-specific accounting/fiscal modules, country-specific carriers and payment methods.
