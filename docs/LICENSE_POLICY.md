# Free redistribution and dependency policy

Nexora Commerce Core is distributed under the MIT license. A base self-hosted installation must not require a paid runtime component, commercial license server, paid SaaS, Redis, external search engine, CDN or proprietary payment provider.

Required runtime dependencies must pass the release dependency-license gate. Unknown licenses fail a production release until reviewed. Optional external integrations are adapters and may have their own terms, but disabling them must not disable the store.
