# Nexora Commerce — анализ: чего не хватает и как стать лучше конкурентов

Дата: 2026-10-11. Версия: 3.97.23 + правки после неё.

## Как сделан анализ и его границы

- Просмотрено: меню админки (около 80 пунктов), модули `src/Modules` (около 50), провайдеры платежей, доставки, фидов, маркетинга, ИИ, API v1, миграции, бонусные темы и расширения, список функций в `CHANGELOG.md`. Проверки «есть / нет» — по коду и поиску по проекту; функция, названная не так, как я искал, может существовать. Такие места помечены «проверить».
- Конкуренты (Shopify, WooCommerce, OpenCart/ocStore, PrestaShop, Magento/Adobe Commerce, BigCommerce; в Украине — Horoshop, Prom.ua, Rozetka-маркетплейс) описаны по моим знаниям на дату обучения. Цены, текущие версии и свежие функции конкурентов не проверялись в интернете.
- Сайт в браузере я не оценивал глазами как дизайнер; UX-замечания основаны на структуре страниц и тестах.

## 1. Что уже сильнее или на уровне конкурентов

Эти вещи у конкурентов часто платные, раздроблены по плагинам или отсутствуют:

- Один движок на все типы сайтов: магазин, лендинг, форум, блог, формы, B2B. Профиль сайта переключает режим.
- Украина «из коробки»: Нова пошта, Укрпошта, Meest, Delivery, LiqPay, Monobank, WayForPay, ПРРО Checkbox (чеки, возвраты), PDF-счета и накладные, ТТН, цены в гривне и валютах.
- ЕС: GDPR-согласия, отзыв договора (14 дней), заявление о доступности, двухфакторная защита, журнал действий.
- Конструкторы: главная, карточка товара, оформление заказа, категория, корзина; визуальный редактор; конструктор форм.
- Автоматизация: правила, авто-письма, брошенные корзины, уведомления в Telegram/SMS, push.
- Современная публикация для поиска: IndexNow, `llms.txt`, hreflang, языковые префиксы, фиды Google/YML/Hotline-подобный XML.
- ИИ: три провайдера (OpenAI, Anthropic, Gemini), массовый перевод.
- Админка: палитра команд (Ctrl+K), сохранённые фильтры, быстрые правки цены и статуса, массовый редактор таблицей, отмена действий, права по ролям, теперь настраиваемый дашборд и перетаскивание.
- Платформа: SDK расширений с подписью пакетов, API v1 и вебхуки, миграция с OpenCart, обновление ядра, снимки восстановления.

## 3. Общее удобство и продуктивность

Что известно по конкурентам и чего в Nexora нет или есть частично.

### Работа с каталогом
- **Быстрое создание товара «в один экран»** (название, цена, фото, категория) с продолжением в полной карточке. Сейчас карточка перегружена, хотя уже упрощалась. У Shopify и OpenCart-тем это самое востребованное.
- **ИИ создаёт карточку по фото, штрихкоду или строке прайса**: название, описание, характеристики, SEO, переводы на все языки.
- Массовые операции: изменить цену на %, перенести в категорию, задать бренд, скрыть — есть частично (массовый редактор). Нужны **массовые действия в списке товаров с предпросмотром и отменой**.
- Планирование публикации товара и скидки по дате — скидка с датой есть, публикация по расписанию проверить.
- **Комплекты и наборы (bundles/kits)** со скидкой и общим остатком. Сейчас есть «с этим покупают» и допы, но не товар-набор.
- Подписки и регулярные заказы (кофе, косметика, корма) — нет.
- Склады: есть одна локация; нет **нескольких складов с перемещениями**, закупочных заказов, серий и сроков годности (важно для еды, косметики, аптек).

### Заказы и фулфилмент
- **Канбан-доска заказов** по статусам с перетаскиванием.
- **Печать пачкой**: этикетки ТТН, накладные, листы подбора. Сборка по штрихкоду.
- Назначение заказа менеджеру, теги, внутренние комментарии с @упоминанием, таймеры SLA («заказ без реакции 30 минут»).
- Разделение отгрузки (часть товаров отправлена), предзаказ по частям.
- **Прибыль по заказу** (себестоимость уже хранится) и отчёт по марже.

### Аналитика
- RFM-сегменты, когорты, LTV, ABC/XYZ-анализ ассортимента, прогноз остатков и точка заказа, отчёт по каналам с расходами на рекламу.
- Сравнение периодов на дашборде, сохранённые отчёты, рассылка отчёта по расписанию (дневной дайджест есть).

### Витрина
- Быстрый просмотр товара во всплывающем окне из каталога (в коде не нашёл).
- Таблица размеров, конфигуратор товара, 360° и видео в галерее (видео есть).
- Живой поиск с исправлением опечаток по умолчанию (Meilisearch подключается отдельно; векторный поиск пропущен по просьбе).
- Подарочный набор, подарочная упаковка (допы есть), «поделиться списком желаний».
- Отзывы с фото уже есть; не хватает метки «проверенная покупка», ответа магазина прямо в ленте отзывов на витрине.
- Выбор темы: готовы `default` и три бонусные (`atelier`, `market`, `soft`). У конкурентов сотни. Нужны **отраслевые пресеты** (одежда, электроника, еда, косметика, услуги, B2B) с демо-данными и предпросмотром.

### Рост продаж
- Партнёрская и реферальная программа («приведи друга»).
- A/B-тесты заголовков, баннеров и цен; поп-апы по сегментам и exit-intent.
- Рассылки: визуальный конструктор писем, сегменты по поведению, SMS/Viber-кампании в одном потоке.
- «Скидка на сегодня», сторис-баннеры, соцдоказательство («купили 12 раз за сутки»).

### Платформа
- **Каталог расширений** (маркетплейс) в админке: SDK есть, но нет витрины, поиска и установки в один клик.
- Копия для тестов (staging) и откат одним нажатием; резервные копии в облако (S3, Google Drive, Dropbox).
- Единый центр уведомлений в шапке админки с группировкой (звонок, заказ, возврат, отзыв).
- Видеоуроки и «первый день»: мастер запуска есть; нужны короткие ролики и пример данных по нише.
- Документация API (OpenAPI есть), коллекция Postman, GraphQL (по желанию).

## 4. Идеи фирменных фишек

Что можно сделать так, чтобы продавцы переходили именно из-за этого:

1. **ИИ-директор магазина.** Каждый день анализирует продажи, остатки, поиск, брошенные корзины и предлагает 3 действия с кнопкой «применить» (поднять цену, запустить акцию, дозаказать товар). Основа есть: монитор качества, ранние предупреждения, дайджест.
2. **Команды обычным языком в палитре Ctrl+K**: «скидка 10% на бренд X до пятницы», «покажи заказы без ТТН». Палитра команд уже есть — не хватает разбора фраз.
3. **Единый рабочий стол маркетплейсов** (U2): заказы и остатки Prom, Rozetka, Epicentr в одном списке, склад общий.
4. **Пакет ФОП/ЕДРПОУ** (U8): лимиты, акты, налоговые выгрузки, ПРРО — всё, что обычно считают отдельно.
5. **Путь роста**: лендинг → несколько товаров → полный каталог → форум/клуб. Профиль сайта уже переключает режимы; нужен мастер «вырос — включить», который переносит данные без потерь и подсказывает следующий шаг.
6. **ИИ-консультант на витрине** на данных каталога (RAG): подбор товара, сравнение, ответы по доставке. База есть (`llms.txt`, ИИ-провайдеры).
7. **«Переезд за 10 минут»** (U9): загрузил экспорт Prom/Horoshop/Shopify — получил готовый магазин с товарами, фото, SEO-адресами и 301-редиректами со старых ссылок.

## 5. Предлагаемый порядок работ

**Ближайшие релизы (макс. эффект за минимальный срок)**
1. U4 — API на запись (основа для всего остального).
2. U1 — оплата частинами.
3. U9 — импорт с Prom.ua / Horoshop / Shopify / WooCommerce.
4. Быстрое создание товара и ИИ-карточка по фото.
5. U6 — Viber и Telegram для покупателя.
6. Канбан заказов и печать пачкой.

**Следующие**
7. U2 — маркетплейсы в обе стороны.
8. U3 — KeyCRM, SalesDrive, Bitrix24, затем BAS/Dilovod.
9. E1/E2 — платежи и перевозчики для ЕС.
10. Отраслевые темы и пресеты.
11. Несколько складов, закупки, серии и сроки.
12. U8 — пакет ФОП.

**Позже**
13. Партнёрка, A/B, подписки, POS, каталог расширений, ИИ-директор.

## 6. Что я не проверил и стоит уточнить

- Реально ли включены Apple Pay/Google Pay и методы региона в Stripe/Monobank-провайдерах (по коду упоминания есть, настроек в админке не видел).
- Как работают VAT OSS, VIES и нулевая ставка в модуле налогов.
- Есть ли публикация по расписанию у товаров и статей.
- Сколько реально складских локаций поддерживает интерфейс (в базе есть таблица локаций).
- Как выглядит витрина на реальных товарах: мобильная версия оценена только автотестами.
