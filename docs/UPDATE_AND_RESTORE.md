# Оновлення та відновлення системи

Ця сторінка для власника магазину без технічних знань. Усе потрібне також є в адмінці: меню користувача (іконка вгорі праворуч) → «Оновлення системи» і «Відновлення».

## Оновити Nexora на новішу версію

Дані магазину (товари, замовлення, клієнти, налаштування, завантажені фото, встановлені модулі) під час оновлення не видаляються: архів не містить `.env`, `.env.local`, `var/` і `public/media/`.

1. **Зробіть резервну копію.** Адмінка → меню користувача → «Відновлення» → «Створити backup» (оберіть «Повний backup: БД + media + система»). Додатково зробіть копію бази на хостингу (phpMyAdmin → Експорт). Завантажте файл backup на свій комп'ютер.
2. **Завантажте новий архів на сервер** і розпакуйте його **поверх** поточного каталогу сайту (той самий каталог, де лежать `public/`, `src/`, `vendor/`). Підтвердьте заміну файлів.
3. **Відкрийте `https://ваш-домен/upgrade.php`.** Введіть `APP_SECRET` (це значення з файлу `.env.local` у каталозі сайту) і натисніть «Оновити систему». Сторінка видалить застарілі файли попередніх версій, очистить кеш і застосує зміни бази даних. Перед застосуванням змін сторінка сама створює резервну копію бази (точка відновлення з причиною `before-upgrade` у розділі «Відновлення»). Це може тривати до хвилини.
4. **Перевірте результат.** Адмінка → меню користувача → «Оновлення системи»: має бути зелене повідомлення «База даних відповідає файлам», а номер версії — новим.

Якщо після розпакування сайт або адмінка не відкриваються — це нормально: просто виконайте крок 3, він це виправляє.

Без браузера (SSH): `php bin/upgrade.php`.

## Що робити, якщо після оновлення щось пішло не так

1. Не панікуйте й не розпаковуйте архів повторно: відкрийте `/upgrade.php` ще раз. Журнал оновлення: `var/log/upgrade.log`.
2. Модуль міг зламати сторінку: Адмінка → Система → Розширення → «Вимкнути» або «Відкотити до попередньої версії». Ядро від цього не страждає.
3. Якщо потрібно повернути все, як було, відновіть backup (нижче).

## Відновити систему з backup

**З адмінки:** меню користувача → «Відновлення». Тут можна створити backup, завантажити його, перевірити, відновити лише дані або завантажити файл backup з комп'ютера й відновити з нього («Відновити backup з ПК»).

**Якщо адмінка не відкривається** (аварійний режим, працює без Symfony і без адмінки), через SSH у каталозі сайту:

    php bin/recovery.php --list
    php bin/recovery.php --inspect КЛЮЧ_BACKUP
    php bin/recovery.php --restore КЛЮЧ_BACKUP --yes

Додаткові ключі: `--database-only` (лише база), `--files-only` (лише файли), `php bin/recovery.php --disable-maintenance` (вимкнути режим обслуговування). Файли backup лежать у `var/recovery/snapshots/`.

## Забули пароль адміністратора

На сторінці входу є «Забули пароль?» (лист із посиланням на 30 хвилин). Якщо пошта ще не налаштована: `php bin/console commerce:admin:reset-password admin@example.com`. Змінити пароль, знаючи поточний: меню користувача → «Профіль і пароль».

## Корисно знати

- Перед кожним оновленням читайте `CHANGELOG.md`: там зазначено, що змінилося.
- Оновлюйте не в годину пік: під час застосування змін бази магазин може відповідати повільніше.
- Версія PHP на сервері має відповідати вимогам: рядок PHP на сторінці «Оновлення системи» показує поточну й мінімальну.
