# example.hello_settings

Декларативний модуль без PHP: паспорт (`manifest.json`), шість полів налаштувань (`settings.schema.json`) та переклади назви.

    php bin/console commerce:extension:pack docs/examples/extensions/hello-settings --output=var/hello-settings.zip

Після встановлення й активації в Система → Розширення біля модуля з'являється кнопка «Налаштування» з цими шістьма полями; кожне збереження стає ревізією, до якої можна повернутися.

Чесно про обмеження: значення лише зберігаються. Жоден публічний інтерфейс (контекст trusted-модуля, Twig, слот) сьогодні не віддає їх модулю, тож вітрину самі по собі вони не змінюють. Поля `multilingual_text` і `multilingual_textarea` у формі налаштувань зараз не зберігаються (форма надсилає один рядок замість значень за мовами), тому в прикладі їх немає.
Докладно: `docs/DEVELOPER_MODULES_UK.md`.
