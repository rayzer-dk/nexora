# Презентаційне демо Nexora Commerce

Демо призначене лише для тестового магазину. Воно використовує ті самі таблиці, SEO Router, каталог, Media та storefront, що й звичайні товари — окремих mock-сторінок для товарів немає.

## Найпростіший спосіб

Під час першого встановлення залиште увімкненим прапорець «Встановити презентаційне демо». Після завершення installer автоматично додасть демонстраційні дані.

## Встановити після звичайної установки

```bash
php bin/console commerce:demo:install
```

Будуть створені (одразу українською, англійською та російською — назви, описи, характеристики, відгуки, адреси):

- 53 категорії з деревом у 4 рівні (електроніка → телефони й планшети → смартфони → Apple iPhone тощо);
- 165 фізичних товарів з цінами, залишками, SKU, брендами, характеристиками та SEO URL;
- товарні фото WebP і галереї: 212 файлів лежать усередині пакета (`resources/demo/images`), інсталятор копіює їх і **нічого не завантажує з мережі**;
- по 2 опубліковані відгуки на товар у кожній мові;
- зв'язки схожих товарів;
- блог: статті з SEO URL і фото та дерево категорій блогу (з підкатегоріями);
- презентаційний hero, банери, блоки переваг і промо на головній;
- чернетки інформаційних сторінок About/Contact/Shipping/Payment/Returns/Warranty/FAQ/Privacy/Cookies/Terms у трьох мовах.

Оновити фото в пакеті (для розробників): `php bin/vendor-demo-images.php` або ручний workflow «Vendor demo images» у GitHub Actions.

## Видалити демо

```bash
php bin/console commerce:demo:remove
```

Команда видаляє лише записи, позначені namespace `demo-<store_id>`, та не повинна торкатися товарів, категорій або контенту, створених користувачем.

## Важливо

Демо-тексти контактів, політик, умов повернення та інших юридичних сторінок не можна використовувати у production як готові юридичні документи. Перед публічним запуском замініть їх фактичними реквізитами та правилами компанії.
