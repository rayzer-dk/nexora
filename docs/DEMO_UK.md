# Презентаційне демо Nexora Commerce

Демо призначене лише для тестового магазину. Воно використовує ті самі таблиці, SEO Router, каталог, Media та storefront, що й звичайні товари — окремих mock-сторінок для товарів немає.

## Найпростіший спосіб

Під час першого встановлення залиште увімкненим прапорець «Встановити презентаційне демо». Після завершення installer автоматично додасть демонстраційні дані.

## Встановити після звичайної установки

```bash
php bin/console commerce:demo:install
```

Будуть створені:

- 4 категорії;
- 6 фізичних товарів з цінами, залишками, SKU, брендами, характеристиками та SEO URL;
- товарні фото WebP і галереї;
- 12 опублікованих відгуків;
- зв'язки схожих товарів;
- 3 статті блогу з SEO URL та фото;
- презентаційний hero, блоки переваг і промо на головній;
- демонстраційний контент інформаційних сторінок About/Contact/Shipping/Payment/Returns/Warranty/FAQ/Privacy/Cookies/Terms.

## Видалити демо

```bash
php bin/console commerce:demo:remove
```

Команда видаляє лише записи, позначені namespace `demo-<store_id>`, та не повинна торкатися товарів, категорій або контенту, створених користувачем.

## Важливо

Демо-тексти контактів, політик, умов повернення та інших юридичних сторінок не можна використовувати у production як готові юридичні документи. Перед публічним запуском замініть їх фактичними реквізитами та правилами компанії.
