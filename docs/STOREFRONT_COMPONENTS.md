# Storefront components

The default storefront includes visible breadcrumbs, responsive product gallery with thumbnails, previous/next controls and native dialog zoom, reusable horizontal slider/carousel based on CSS scroll-snap, product reviews, related products, blog/CMS content engine and Product Page Composer blocks.

Simple sliders do not pull Swiper or another large global dependency. The lightweight custom element is loaded only on pages that use it. More specialized extensions may provide a different carousel behind the same component contract.

The default font strategy is system-first for speed and privacy. Licensed WOFF2 variable fonts can be self-hosted and selected in Appearance. Remote font CDNs are opt-in.
