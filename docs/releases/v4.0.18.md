# Nexora Commerce 4.0.18

This release consolidates and validates the lightweight UI motion improvements added to the storefront and administration.

## Storefront
- Accessible animated icons, product card feedback, wishlist confirmation and fly-to-cart.
- Skeleton loading for the cart and catalog updates, animated gallery/photo transitions, toast lifetime indicators.
- Improved search feedback, product availability transitions and checkout progress.
- Persistent visitor choice of full, minimal or disabled motion; system reduced-motion always takes priority.
- Native CSS scroll-snap carousels and gesture support; no Swiper, Owl Carousel, Lottie or other motion libraries added.

## Administration
- Loading indicators for actual server requests, verified success feedback and transient copied checkmarks.
- Feedback for status edits, category expansion, import batches and image queues.
- Persistent motion preferences within the administrator menu.

## Compatibility and safety
- No database migration and no additional runtime dependencies.
- Existing PHP 8.4+ and MySQL/MariaDB support maintained.
- Production archive is uploaded only after all required checks on the exact current main commit succeed. The archive is accompanied by a SHA-256 checksum.
- No automatic deployment to a live store.
