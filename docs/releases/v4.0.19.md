# Nexora Commerce 4.0.19

## Administration: unique errors in the log viewer
- Logs and errors: the new **Unique errors** button groups the currently filtered entries of the opened log file by type, normalized message and place in the code (file and line). Every unique error is shown once with its number of repeats, the first and the last time stamp. Numbers, identifiers and UUIDs inside messages do not split a group.
- **Reset filter** returns to the plain journal with every entry and every repeat in the original order. The plain journal is not analysed again.
- **Copy selected** copies the ticked unique errors as one text (type, message, file, line, repeats). Select all is available.
- Header: the log icon shows the number of unique errors of all log files. The number is cached per file for 60 seconds and is recomputed at once when a file shrinks or is cleared.
- The log files are only read, never modified. Grouping reads the last 16 MB of the file backwards in 256 KB chunks and keeps at most 2000 groups, so memory is bounded. After the standard "Clear file" the counter starts from zero and an error that happens again is shown again.
- New texts in Ukrainian, Russian and English.

## Compatibility and safety
- No database migration and no new runtime dependencies.
- Viewing, downloading and clearing of logs, and the way errors are written, are unchanged.
