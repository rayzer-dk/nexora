# Nexora Commerce 4.0.21

- Performance: native Vite minifiers, lazy carousel initialization, streamlined catalogue requests, bounded category queries, faster admin tables, cached facet projections and reduced background animation activity.
- Images: restrict generated formats, collect stale variants, optional disk budget and idle eviction, storage statistics, reuse identical small image data and omit regenerable cache from backups.
- Dependencies: stable Symfony 8.1 security patches, Twig 3.31.1, Doctrine Migrations 3.10.0, Vite 8.4.0, Lucide Vue 1.82.0, CodeMirror View 6.44.2, Commands 6.11.2, Playwright 1.65.1 and axe-core Playwright 4.14.1. Tiptap remains 3.35.0 pending compatible peer resolution. Symfony 8.2 RC is evaluated separately; no prerelease in production.
- Installer: verifies Composer 2 runtime metadata and built Vite asset integrity before allowing installation. Image cache policy defaults remain disabled and are included in environment setup.
- Database schema stays at 91; no new migrations.

- Appearance: seven configurable storefront concepts including Forest, distinct palettes, navigation and card interactions, responsive and dark-mode captures, contrast and zoom checks.
