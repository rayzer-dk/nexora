# Перший модуль за 10 хвилин

Модуль Nexora — це ZIP-пакет, який додає налаштування, переклади, блоки або інтеграцію **без змін у файлах ядра**. Його можна встановити, увімкнути, вимкнути, оновити, відкотити й видалити з адмінки. Нижче — найпростіший модуль (декларативний, без PHP-коду): він має власну сторінку налаштувань в адмінці.

Повний довідник: [EXTENSION_SDK.md](EXTENSION_SDK.md), типи налаштувань: [EXTENSION_SETTINGS_SCHEMA.md](EXTENSION_SETTINGS_SCHEMA.md), готові приклади: [README.md](README.md).

## 1. Створіть заготовку

У каталозі сайту (через SSH або термінал):

    php bin/console commerce:extension:scaffold acme.hello --name="Hello" --preset=basic

Код модуля має вигляд `виробник.назва` (малі літери, цифри, `_`). З'явиться каталог `var/extension-scaffold/acme.hello/` з файлами:

| Файл | Для чого |
| --- | --- |
| `manifest.json` | паспорт модуля: назва, версія, що він додає |
| `settings.schema.json` | які поля налаштувань побачить власник магазину |
| `translations/uk-UA/messages.json`, `translations/en-US/messages.json` | тексти українською й англійською |
| `README.md` | нагадування для вас |

Інші заготовки: `--preset=product-block` (блок на сторінці товару), `--preset=remote-integration` (інтеграція з зовнішнім сервісом), `--preset=theme` (тема), `--preset=trusted-route` (власні маршрути, потребує підпису).

## 2. Змініть налаштування під себе

Відкрийте `settings.schema.json` і додайте поле, наприклад текстове. Типи полів: `text`, `textarea`, `number`, `boolean`, `select`, `url`, `email`, `secret`, `color` та інші (див. EXTENSION_SETTINGS_SCHEMA.md). Підпис поля й підказку пишіть зрозумілою мовою власника магазину.

## 3. Запакуйте й перевірте

    php bin/console commerce:extension:pack var/extension-scaffold/acme.hello --output=var/acme.hello.zip

Команда збирає ZIP і одразу перевіряє його. Окремо: `commerce:extension:validate var/acme.hello.zip` (перевірка) та `commerce:extension:test var/acme.hello.zip` (перевірка SDK). Якщо є помилка, текст пояснює, що виправити.

## 4. Встановіть в адмінці

Адмінка → Система → Розширення:

1. Оберіть ZIP і натисніть **«Перевірити ZIP-пакет»**. Пакет перевіряється й готується, але **нічого не вмикається автоматично**.
2. Натисніть **«Активувати»** біля перевіреного пакета.
3. Біля модуля з'явиться кнопка **«Налаштування»**: тут власник магазину змінює поля з вашого `settings.schema.json`. Кожне збереження створює ревізію, до якої можна повернутися.

## 5. Вимкнути, оновити, відкотити, видалити

- **Вимкнути**: модуль перестає працювати одразу, дані лишаються.
- **Оновити**: завантажте ZIP з новішою `version` у `manifest.json`: стара версія зберігається й доступна для відкату («Відкотити до»).
- **Видалити**: лише для неактивної версії. Оберіть варіант «З даними модуля», якщо потрібно прибрати й його таблиці.

## Що далі

- Блок на сторінці товару, слот на сторінці, пункт меню: [EXTENSION_SLOTS.md](EXTENSION_SLOTS.md).
- Власна логіка (PHP), події, cron, міграції: потрібен підписаний пакет `trusted_release`, див. розділи SDK «Trusted» та «Scheduled tasks».
- Правило: модуль **ніколи** не правит файли ядра, не лізе в чужі таблиці й оголошує все, що використовує, у `manifest.json`.
